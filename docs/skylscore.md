# SkylScore

SkylScore is a transparent 1–10 competitiveness index designed to help students compare opportunities.

It is **not** an admissions prediction.

## Factors

| Factor | Weight |
|---------|-------:|
| Acceptance Rate | 40% |
| Applicant Pool Size | 20% |
| Institutional Reputation | 20% |
| Scholarship Value / Program Cost | 10% |
| Application Complexity | 10% |

## Purpose

SkylScore provides a consistent way to compare opportunities using publicly available information.

Higher scores indicate opportunities that appear more competitive.

## Limitations

Many organizations do not publish complete statistics.

SkylScore should be interpreted as a comparison tool rather than a guarantee of competitiveness or admissions outcomes.
